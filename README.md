# Prometheus Procurement V10.8.15

Modern Contracts Workspace release.

## Run

```text
run_prometheus.bat
```

Or:

```text
python Prometheus_V10_8_15.py
```

## Contracts workspace

- Contracts are shown by Delivery Date, newest first by default.
- Delivery Date is visible as a primary table column.
- The Order selector offers alternate operational views without changing saved data.
- Export All creates a complete portfolio workbook.
- Export Visible creates an Excel workbook for the active commodity/status/origin/search filters.
- Compare 2 opens a side-by-side contract comparison and can export it to Excel.
- The workbook contains Summary, Contracts and Pricing Lots sheets.
